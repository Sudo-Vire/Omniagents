# Authors & Contributors (OmniAgent)

**OmniAgent** integrates and orchestrates open-source AI agents, skills, and tools contributed by the wider AI and developer community, combined with custom-built orchestration frameworks created by **Sudo-Vire**.

## Core Maintainer & Creator
- **Sudo-Vire** — Project Lead, Creator of Custom Orchestration Frameworks (`orchestration/`), and Integration Architect.

## AI Runtimes & SDKs
- **Google DeepMind & GitHub Copilot SDK** — Foundational Copilot SDK, agent host runtime, and VS Code AI integration (`orchestration/agents/copilot-instructions.md`).
- **Anthropic Claude & Claude Code** — Advanced reasoning models and tactical micro-subagents framework (`orchestration/agents/claude-instructions.md`, `pre-downloaded/agents/claude-subagents`).
- **Google Gemini** — Large-context code analysis and fast model execution (`orchestration/agents/gemini-instructions.md`).
- **OpenAI** — API specifications, model runtimes, and embedding interfaces.

## Security & Knowledge Graph Tools
- **Strix Security Team** — Autonomous AI penetration testing, vulnerability discovery, and exploit validation framework (`pre-downloaded/skills/strix`).
- **Graphify Contributors** — Knowledge graph generation, god nodes, and structural codebase mapping engine (`pre-downloaded/skills/graphify`).

## Agents & Skills Ecosystem
- **Andrej Karpathy** — Development workflow routines, git guidelines, and coding practices (`pre-downloaded/skills/andrej-karpathy-skills`).
- **Agency Agents Contributors** — Domain-specific macro-agents across engineering, design, data science, strategy, and security (`pre-downloaded/agents/agency-agents`).
- **Superpowers Contributors** — Advanced reasoning, systematic debugging, brainstorming, and tool extension plugins (`pre-downloaded/skills/superpowers`).
- **UI/UX Pro Max Creators** — Interface design intelligence, color palettes, and accessibility guidelines (`pre-downloaded/skills/ui-ux-pro-max`).
- **Vercel Engineering** — React, Next.js performance guidelines and view transition patterns (`pre-downloaded/skills/vercel-*`).
- **Open-Source Community** — General skills (GSD, writing guidelines, web design guidelines, Vercel CLI).

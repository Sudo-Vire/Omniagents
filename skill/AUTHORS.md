# Authors & Contributors (OmniAgent)

**OmniAgent** integrates and orchestrates open-source AI agents, skills, and tools contributed by the wider AI and developer community, combined with custom-built orchestration frameworks created by **Sudo-Vire**.

## Core Maintainer & Creator
- **Sudo-Vire** — Project Lead, Creator of Custom Orchestration Frameworks (`skill/framework/orchestration/`), and Integration Architect.

## Security & Knowledge Graph Tools
- **Strix Security Team** — Autonomous AI penetration testing, vulnerability discovery, and exploit validation framework (`skill/dependencies/utils/skills/ciberseguridad/`).
- **Graphify Contributors** — Knowledge graph generation, god nodes, and structural codebase mapping engine (`skill/dependencies/utils/skills/graphify`).

## Agents & Skills Ecosystem
- **Andrej Karpathy** — Development workflow routines, git guidelines, and coding practices (`skill/dependencies/utils/skills/andrej-karpathy-skills`).
- **Agency Agents Contributors** — Domain-specific macro-agents across engineering, design, data science, strategy, and security (`skill/dependencies/utils/agents/agency-agents`).
- **Superpowers Contributors** — Jesse Vincent and contributors (`obra/superpowers`, MIT): advanced reasoning, systematic debugging, brainstorming, and tool extension plugins (`skill/dependencies/utils/skills/superpowers`).
- **VoltAgent Contributors** — Granular tactical Claude subagent catalog (`VoltAgent/awesome-claude-code-subagents`, MIT) (`skill/dependencies/utils/agents/claude-subagents`).
- **UI/UX Pro Max Creators** — Interface design intelligence, color palettes, and accessibility guidelines (`skill/dependencies/utils/skills/ui-ux-pro-max`).
- **Vercel Engineering** — React, Next.js performance guidelines and view transition patterns (`skill/dependencies/utils/skills/vercel/`).
- **Open-Source Community** — General skills (GSD, writing guidelines, web design guidelines, Vercel CLI).

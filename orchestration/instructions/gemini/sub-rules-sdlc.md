# SDLC & Workflow Guidelines (Modular Subfile)

## SDLC – Software Development Life Cycle (General Cycle)
Every task follows these 8 phases with mandatory thinking out loud, planning, and explicit user confirmation before execution:
- **Phase 1**: Requirements & Planning (Superpowers + Karpathy Skills)
- **Phase 2**: Design (UI/UX, accessibility)
- **Phase 3**: Development & Implementation (Surgical coding)
- **Phase 4**: Security & Compliance (OWASP audit, Strix pentesting)
- **Phase 5**: Testing & QA (Unit, E2E, Browser-Use visual validation)
- **Phase 6**: Git Workflow & Version Control (Conventional Commits, branching)
- **Phase 7**: Deployment & DevOps (Cloudflare)
- **Phase 8**: Maintenance, Support & Research

## Complete Git Standard
- Branch naming: `feature/`, `bugfix/`, `hotfix/`, `refactor/`, `docs/`.
- Conventional Commits: `type(scope): description`.
- Changelog generation via `git-cliff -o CHANGELOG.md`.

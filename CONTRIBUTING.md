# Contributing to Omniagents

Thank you for your interest in contributing to **Omniagents**! We welcome contributions of new agents, skills, tools, bug fixes, and documentation improvements.

## Development Workflow

1. **Fork the Repository** and clone your fork.
2. **Create a Feature Branch**:
   ```bash
   git checkout -b feature/amazing-agent
   ```
3. **Run the Installer**:
   ```bash
   python install.py
   ```
4. **Make Your Changes**:
   - Follow existing code style and structure.
   - Keep changes modular and surgical.
5. **Verify Syntax**:
   ```bash
   make lint
   ```
6. **Commit and Push**:
   ```bash
   git commit -m "feat(agents): add amazing new agent"
   git push origin feature/amazing-agent
   ```
7. **Open a Pull Request** against `master`.
